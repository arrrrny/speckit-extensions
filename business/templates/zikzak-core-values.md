# ZikZak AI — Core Values (seeded by the business extension)

These are the operator's non-negotiables. The `business` commands read them to
keep alignment honest: a task that serves the mission but violates these values
(e.g. a manual process when AUTOMATION is pledged, or a "good enough" commit when
WTF OR NOTHING rules) is flagged even when it looks productive.

### Operating cadence extracted from the motto

- **Segments** — the workday is split into segments; one bottle of lemon water
  per segment. The first segment is done **standing** (confidence boost).
- **Automate 1 process every day** — a daily non-negotiable, separate from the
  "one task by 2 PM." The `daily` command can log this as a second line.
- **Release cadence** — ship on **Tuesdays and Fridays** only.
- **Explain out loud** — code is narrated as if an assistant (and future
  audience) is watching; this is the streamer rep.
- **North-star feeling** — DEALS that make people say **WTF!**

## Values the commands enforce

| Value | What it means for a task |
|-------|--------------------------|
| PROCESSES OVER PRODUCTS | Prefer building the repeatable process over a one-off feature. |
| AUTOMATION | A task that adds manual toil is suspect; automate or delegate. |
| EXCELLENCE / WTF OR NOTHING | "Good enough" commits fail the bar; v1 must impress. |
| SPEED OF IMPLEMENTATION | Favor shipping the smallest detonating version over polishing. |
| AUTOMATE 1/DOMAIN | The daily log tracks the one process automated that day. |
| RELEASE Tue & Fri | `review` notes whether the next release lands on a release day. |
| AI to find DEALS (WTF) | The user-facing payoff is deals so good they shock — the KPI levers (scan/share/ask) exist to surface those. |
